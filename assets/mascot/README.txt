# Mascot Assets Folder

Drop your custom 2D mascot PNG images here to replace the built-in programmatic vector mascot!

Supported filenames (PNG with transparent background recommended, ~200x200 px):
- `good.png`        : Displayed when sitting upright with good posture (happy/cheerful).
- `warning.png`     : Displayed when posture starts slouching (< 5s) (concerned/curious).
- `slouch.png`      : Displayed when sustained slouching exceeds 5s (sad/alerting).
- `calibrating.png`: Displayed during the 1-second calibration hold (focused).
- `neutral.png`    : Displayed before calibration is completed.
- `sleep.png`      : Displayed when no person is detected in front of the camera.

If any of these images are missing, Posture Guardian automatically falls back to its built-in interactive vector avatar.
